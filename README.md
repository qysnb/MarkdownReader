# Markdown Reader

An Android-first, read-only Markdown reader focused on fast loading, native rendering, and local history.

## Current features

- Manual folder import through the system picker
- Optional recursive scan of subfolders
- Recent documents list with persisted open history
- Last reading position per document
- Native text rendering with Markwon and LaTeX support

## Notes

- This workspace currently contains source only.
- To build the app, open the project in Android Studio or a Gradle-enabled Android environment.
